# Car Accident Prediction Model 🚗⚡

An AI-powered dashboard that predicts the probability of severe or fatal injuries in road accidents using real-world data (based on the UK Road Accidents Dataset).

## Features
- **Deep Learning Model**: A TensorFlow/Keras neural network trained on 8 critical environmental and vehicular parameters.
- **Flask API Backend**: Instantly serves risk predictions via a fast HTTP endpoint.
- **Premium Dashboard**: A highly interactive, modern glassmorphic interface built with HTML, CSS, and Vanilla JS that dynamically visualizes risk levels.

## Tech Stack
- **AI/ML**: Python, TensorFlow, scikit-learn, Pandas, Joblib
- **Backend**: Flask
- **Frontend**: HTML5, CSS3, Vanilla JavaScript

## Setup & Run Locally
1. Ensure you have Python installed and create a virtual environment if desired.
2. Install the necessary dependencies:
   ```bash
   pip install tensorflow pandas scikit-learn flask joblib
   ```
3. Start the Flask Web Server:
   ```bash
   python app.py
   ```
4. Open your browser and navigate to `http://127.0.0.1:5000` to interact with the dashboard!
